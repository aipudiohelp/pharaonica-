PHARAONICA — GLOBAL FOOTPRINT
=============================
index.html is a standalone responsive section with embedded CSS and JavaScript.

No real countries, cities, clients, or projects are preloaded. This is intentional.
After the client approves the locations, edit VERIFIED_LOCATIONS in the script:
{country, city (optional), x, y, type, year (optional), description (optional)}
Coordinates x/y are percentages of the illustrative map's 1000 x 440 viewBox.

The map is a stylized illustration, not a geographic GIS map. For exact map positioning, replace it with a properly licensed geographic SVG or mapping library. Test the section alongside the existing site's styles before publishing.
